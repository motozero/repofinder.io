# RepoFinder product demo V3 storyboard

## Narrative promise

The viewer should understand one transformation without learning repository jargon:

`A vague product idea → evidence-backed options → a personal constraint → a focused experiment`

## Visual system

- 16:10 canvas, matching the existing RepoFinder deck.
- Dark charcoal background with mint and blue accents.
- Yellow is reserved for “look here” notes, outlines, and arrows.
- One primary idea per slide.
- Screenshots are real product captures. They are cropped tightly enough to remain readable.
- Post-it notes explain why a highlighted control or answer matters. They do not repeat the headline.
- Arrows and outlines are anchored inside the screenshot frame so they stay aligned.

## Scene 1, the idea

- **Narrative role:** Establish a human outcome before showing the tool.
- **Visual:** Large live portfolio screenshot on the left. Headline and a yellow note on the right.
- **Callout:** Yellow outline around the portrait area. Arrow from “Goal: add an AI video avatar.”
- **Value:** The viewer immediately understands the desired experience.

## Scene 2, give the idea context

- **Narrative role:** Show the minimum input required.
- **Visual:** Tight crop of the RepoFinder hero and primary form. The example combinations section is not shown.
- **Callouts:** Yellow outline around the primary form and a smaller outline around Find repos.
- **Post-it:** “The site and goal change the answer.”
- **Value:** The tool starts with the viewer’s situation, not a generic category search.

## Scene 3, reveal the tradeoff

- **Narrative role:** Create tension and show why the ranking is useful.
- **Visual:** Enlarged real Duix-Avatar result card on the left. A concise tradeoff panel on the right.
- **Callouts:** Star count, ease score, and GPU requirement.
- **Post-it:** “Powerful is not the same as easy.”
- **Value:** RepoFinder exposes adoption and implementation cost together.

## Scene 4, add the constraint

- **Narrative role:** Demonstrate that the first answer is a starting point.
- **Visual:** Dimmed real results screenshot with one large user chat bubble above it.
- **Callout:** Yellow note: “This is the requirement the star count cannot know.”
- **Value:** The user can express taste, constraints, and willingness to pay.

## Scene 5, watch the answer change

- **Narrative role:** Deliver the payoff.
- **Visual:** Real chat crop on the right. Short explanation on the left.
- **Callout:** Yellow outline around the assistant response.
- **Post-it:** “Hosted beats self-hosted for this project.”
- **Value:** The answer changes from an infrastructure project to practical hosted choices.

## Scene 6, turn the answer into an experiment

- **Narrative role:** Convert research into action.
- **Visual:** Four connected cards: need, constraint, choice, test.
- **Selected path:** HeyGen prototype on one portfolio page.
- **Post-it:** “Test the experience before the architecture.”
- **Value:** The user leaves with a small, measurable next step.

## Scene 7, one capability for humans and agents

- **Narrative role:** Show reuse without interrupting the main story.
- **Visual:** Browser card on the left, shared engine in the center, MCP card on the right.
- **Human path:** Search, inspect, and refine through conversation.
- **Agent path:** Call `recommend_repos` and receive structured results.
- **Value:** The same capability supports an interactive demo and repeatable agent workflows.

## Scene 8, the value

- **Narrative role:** Restate the changed outcome.
- **Visual:** One large result line and three value cards.
- **Result line:** `letsgochristo.com + AI video avatar → HeyGen prototype`
- **Value cards:** Less tab hopping. Fewer wrong-fit integrations. Faster path to a test.
- **CTA:** Open the live demo or inspect the MCP tool.

## Approval gate

Before any ElevenLabs or video work:

1. Approve the eight-scene story.
2. Approve or revise the narration.
3. Approve the visual callouts and diagram.
4. Confirm the ElevenLabs voice.
5. Then generate one audio file per scene and assemble the timed video.
