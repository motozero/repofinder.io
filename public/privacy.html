Privacy

RepoFinder is a public technical demo. It records visits and interactions so the owner can operate the service and understand how people use it.

What is recorded

For page visits and product interactions, RepoFinder stores an allowlisted request record in its Cloudflare D1 database. It can include the page path, time, raw IP address, user agent, browser and device labels, referrer, approximate city and region, network and ASN, Cloudflare data center, language, protocol, TLS version, and connection timing. Some fields depend on what Cloudflare provides and may be unavailable.

Searches include the project and goal you submit. Chat sessions include your full questions and RepoFinder’s full responses. Contact messages include the name, email, and message you choose to submit.

Notifications

Only completed analyses can be sent to the site owner through a private Telegram bot. The alert includes the submitted project or website, the goal, and the request fields described above. Page visits, contact messages, repository clicks, and chats do not trigger Telegram alerts. Chats remain available in D1.

What is excluded

The telemetry allowlist does not copy cookies, authorization headers, URL query strings, or request bodies. Do not submit passwords, API keys, private source code, or other secrets in a search, contact form, or chat.

Your choices

If you do not want a chat stored for the site owner, do not use the chat feature. For questions or deletion requests, use the contact form.
