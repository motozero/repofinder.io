THE BUILD BEHIND THE DEMO

From a hackathon insight to a reusable developer tool

Open source is usually easy to try once you know the right project. Discovery is the hard part. RepoFinder turns a codebase and a goal into a short, evidence-backed list of tools that a developer can evaluate quickly.

It grew out of RepoRadar.io, which placed second out of 302 teams at a global generative UI hackathon. I rebuilt the core idea as an OpenAI-native demo with a clearer provider boundary, structured outputs, model routing, evals, and a fallback path that keeps the experience useful when the model is unavailable.

One recommendation engine serves both the browser API and a remote MCP tool. A checked-in Codex skill shows an agent when to call that tool. The deployment is isolated in its own Cloudflare Worker, D1 database, domain, and secrets.

I am Christo Roberts. The complete source, architecture notes, eval harness, and lesson book are public so the demo is useful after the first “whoa.”
