Frequently asked questions

What does RepoFinder recommend?

Installable open source projects that complement your codebase. It filters out tutorials, starter kits, archived projects, and obvious substitutes when better tools are available.

What signals does it use?

OpenAI analyzes the source and explains project-specific fit. GitHub supplies repository metadata, stars, forks, recent commits, contributor counts, language, and maintenance status.

What happens if OpenAI is unavailable?

The request falls back to deterministic ranking over live GitHub data. The interface labels the mode, so graceful degradation never looks like model output.

Can an agent use it?

Yes. The same engine is exposed as the recommend_repos tool at the remote MCP endpoint. The repository includes a Codex skill that teaches an agent when and how to call it.

What data does RepoFinder keep?

RepoFinder stores searches, coarse Cloudflare location and network signals, browser and operating system labels, and anonymous interaction IDs so the owner can understand the demo. It does not store raw IP addresses or user-agent strings. Contact messages contain the details you choose to submit.

Are recommendations safe to ship?

They are candidates, not approvals. Check the license, security posture, API stability, and your own requirements before production use. RepoFinder makes that evaluation faster, but it does not replace it.

Is the deployment connected to RepoRecommender?

No. RepoFinder has its own GitHub repository, Cloudflare Worker, D1 database, domain, and production secrets.
